# 조작 가이드 (비개발자용)

이 프로그램을 직접 다루는 법. 개발 지식 없이 따라 할 수 있게 썼다.

## 1. 시작하기

1. Unity Hub 에서 이 폴더 열기 (Unity **6000.5.10f1**).
2. 상단 메뉴 **FluidStabilizer ▸ Rebuild Play Scene**.
3. `Assets/FluidStabilizer/Scenes/PlayScene.unity` 을 열고 **Play ▶** 누르기.

씬이 이상하면 2번을 다시 하면 된다.

## 2. 설정 패널 — 백틱 키 `` ` ``

화면 오른쪽 위 "`` ` ``(백틱): 설정 패널" 을 눌러 연다. (키보드 `Esc` 아래, `1` 왼쪽)

- **도로 프리셋**: 평지 / 일반 고속도로 / 비포장 / 굽은 길 / 급경사 / 빗길 / 눈길.
  누르면 관련 값(거칠기·굽음·경사·접지력·채움)이 한 번에 바뀐다.
- **슬라이더**: 채움(fill), 탱크 높이, 도로 거칠기, 굽은 정도, 오르내림,
  접지력(낮을수록 미끄러움), **미끄러짐 격렬함**(미끄러진 뒤 얼마나 요동치나 —
  0 없음 / 0.5 순함(기본) / 1 이상 거셈), 운전자 종류/강도, 슬로시 모델.
- **[적용 (씬 재시작)]**: 바뀐 값을 `experiment.txt` 파일에 저장하고 시뮬을
  다시 시작한다. **적용을 눌러야 실제로 반영된다.**
- **[되돌리기]** 파일 값으로, **[기본값으로]** 공장 초기값으로.

화면 왼쪽 위 HUD 에 지금 적용된 프리셋과 값이 항상 표시된다. 값을 바꾸고
적용했는데 HUD 가 그대로면 적용이 안 된 것.

> `experiment.txt` 는 텍스트 편집기로 직접 열어 고쳐도 된다. 패널과 파일은
> 같은 값을 본다.

## 3. 직접 운전

| 키 | 동작 |
|---|---|
| **W / S** | 가속 / 제동 |
| **A / D** | 조향 |
| **Space** | 스태빌라이저 켜기/끄기 (차이를 느껴봐) |
| **0 ~ 4** | 스태빌라이저 선택 — 0 강체 · 1 SFA · 2 PID · 3 특권(치트) · **4 학습 정책** |
| **M** | 슬로시 모델 (진자 ⇄ 얕은물) |
| **G** | 도로 켜기/끄기 |
| **R** | 리셋 |
| **T** | 슬로모 |
| **Tab** | 카메라 |
| **P** | 주행 녹화 시작 / 다시 눌러 저장 |
| **L** | 최신 녹화 재생 |
| **C** | 3분할 비교 |

## 4. 주행 녹화하기

**P** → 운전 → **P**. `Traces/drive-<시각>.trace.csv` 로 저장되고 콘솔에 전체
경로가 찍힌다. 판별력 있는 주행을 원하면 **도로 켜고(`G`)** 탱크를 꽤 채운
상태(55% 이상)로. 재생(`L`) 중에는 운전이 안 되고, `0~4` 로 스태빌라이저만
바꿔 같은 주행을 비교할 수 있다.

## 5. ③ 학습 정책 서버 (기초)

③(학습 정책)은 **Unity 밖에서 도는 Python 프로세스**(`serve_policy.py`)가
담당한다. Unity 는 그 프로세스에 TCP 로 연결한다.

### 켜는 법
- **설정 패널 → "정책 서버 (③)" 섹션 → [서버 시작]**.
  에디터에서 자동으로 `python/.venv` 파이썬으로 최신 체크포인트를 띄운다.
- 안 되면(체크포인트 없음 등) 터미널에서 직접:
  ```bash
  cd python
  .venv/bin/python serve_policy.py --checkpoint runs/bc/actor.pt --port 5601
  ```

### 켜졌는지 확인
- 설정 패널의 상태등: **● 실행 중** (초록) / **○ 꺼짐** (주황). 2초마다 갱신.
- ③ 스태빌라이저를 켰을 때 HUD 의 "stabilizer:" 줄이
  `Learned policy @127.0.0.1:5601` 이면 연결됨,
  `... offline → Hold` 면 서버가 없어서 강체처럼 동작 중.

### 끄는 법
- 패널에서 켰으면 **[서버 중지]**. (Unity Play 를 멈춰도 자동 정리된다.)
- 터미널에서 켰으면 그 터미널에서 **Ctrl+C**.

## 6. 3분할 비교 (C)

**C** 를 누르면 최신 녹화 주행을 **① 강체 · ② PID · ③ 학습** 세 가지로 동시에
재생한다. 화면이 가로 3칸으로 나뉘고 각 칸이 자기 트럭을 보여준다 — **같은
주행, 같은 길, 처리 방식만 다름.** 각 칸에 넘친 리터가 크게 표시되고, 가장 적게
넘친 칸에 초록 테두리. 다시 **C** 로 나간다.

③ 칸이 "(offline→Hold)" 면 5번을 먼저. 세 칸이 다 끝나면 아래에 한 줄 판정
("① 강체가 가장 적게 넘쳤다 …")이 뜬다.

## 6b. 결과 로그 (`Logs/episodes.csv`)

3분할 비교와 헤드리스 평가(메뉴 **FluidStabilizer ▸ Evaluate Recorded Drives** /
**Evaluate Learned Policy**)는 끝난 에피소드마다 한 줄을 `Logs/episodes.csv` 에
**덧붙인다** — 운영점(fill·탱크높이·도로·grip)과 결과(넘친 리터·최소 freeboard·
슬로시에너지·액추에이터 노력/포화)가 한 행. 스프레드시트로 열어 실행들을
누적 비교하거나 그래프를 그릴 수 있다. `Logs/` 는 git 에 안 올라간다.

## 7. standalone 앱 빌드

메뉴 **FluidStabilizer ▸ Build Standalone App** →
`Builds/fluid-stabilizer-StandaloneOSX/fluid-stabilizer.app`. 더블클릭으로 실행.
(빌드된 앱에서는 정책 서버를 터미널에서 직접 켜야 한다 — 5번 참고.)

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| `-executeMethod` / 테스트가 멈춰 있음 | Unity 에디터를 닫고 `Temp/UnityLockfile` 삭제. Unity 는 프로젝트당 하나만 열림 |
| 설정 패널 [적용] 했는데 안 바뀜 | HUD 왼쪽 위 프리셋/값 확인. 재생(`L`) 중이면 트레이스가 우선이라 무시됨 |
| ③ 서버가 계속 "꺼짐" | 포트 5601 충돌? 터미널에서 `lsof -iTCP:5601` 확인. 체크포인트 있나? `python/runs/` |
| 서버 [시작] 이 "체크포인트 없음" | 먼저 학습 필요. `docs/rl.md` 5.C 참고 |
| 빗길/눈길에서 안 미끄러짐 | 급브레이크·급조향을 해야 한계를 넘어 미끄러진다. 미끄러지면 HUD 에 "⚠ 타이어 미끄러짐" 표시. 눈길(grip 0.38)이 빗길(0.6)보다 잘 미끄러짐 |
| 미끄러질 때 너무 홱홱 돌아 운전이 안 됨 | "미끄러짐 격렬함" 슬라이더를 낮춰라 (기본 0.5). 반대로 더 거세게: `experiment.txt` `slipIntensity: 1.5`+ |
